Site institucional desenvolvido para a **Clínica Eliane Brait**, com foco em apresentar a clínica, a equipe de profissionais e facilitar o contato de novos pacientes. O projeto foi construído **inteiramente com HTML** (com CSS e JavaScript integrados), sem nenhum framework e sem back-end — uma escolha de arquitetura pensada para manter o site leve, rápido e fácil de hospedar sem custo de servidor.

Este é um projeto real, feito para uma clínica de fisioterapia, com foco em:

- Apresentação profissional da marca e da equipe
- Facilitar o primeiro contato do paciente com o mínimo de fricção possível
- Localização clara e acessível da unidade

## ✨ Funcionalidades

- 🏠 **Página institucional** com apresentação da clínica e sua proposta
- 👩‍⚕️ **Equipe de profissionais**, com foto e especialidade de cada um
- 💬 **Atendimento online** — formulário de contato que envia a mensagem preenchida direto para o WhatsApp da clínica, sem precisar de back-end
- 📍 **Localização integrada com Google Maps** — ao clicar no mapa, o visitante é redirecionado direto para a rota até a clínica
- 📱 **Totalmente responsivo**, adaptado para celular, tablet e desktop

## 🛠️ Tecnologias utilizadas

| Tecnologia | Uso |
|---|---|
| **HTML5** | Estrutura, estilização e interações — projeto construído em HTML puro |
| **Google Maps** | Localização da clínica com link direto para rota |
| **WhatsApp API (wa.me)** | Encaminhamento do formulário de contato direto para o WhatsApp |

| **GitHub Pages** | Hospedagem e deploy |

## 🚀 Como rodar localmente

Não é necessário instalar nada. Basta clonar o repositório e abrir o `index.html` no navegador:

```bash
git clone https://github.com/wallace-2105/clinica-eliane-brait.git
cd clinica-eliane-brait
```

Depois é só abrir o `index.html` direto no navegador, ou usar uma extensão como o **Live Server** (VS Code) para um ambiente com recarregamento automático.

## 💬 Sobre o formulário de contato

O formulário de "Atendimento online" foi feito para funcionar **sem nenhum back-end**: os dados preenchidos pelo paciente (nome, mensagem, etc.) são formatados e enviados como uma mensagem pronta direto para o WhatsApp da clínica através do link `wa.me`, abrindo o WhatsApp Web ou o app já com o texto preenchido.

Essa abordagem elimina a necessidade de servidor, banco de dados ou API própria para receber contatos — o WhatsApp já atua como o "back-end" de atendimento.

## 📍 Sobre a localização

O endereço da clínica é exibido com um mapa incorporado do Google Maps. Ao clicar sobre ele, o visitante é redirecionado automaticamente para o Google Maps (app ou navegador) já com a rota até a unidade, facilitando o deslocamento de pacientes.
